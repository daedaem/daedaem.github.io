## 평가 뒤에 고친 것

### 시안(NEW)
- 평가 A·B 뒤: 위키 필터가 고정 머리줄 밑에서 검색창을 가리던 버그, 필터 라벨·상태 설명, 카드 날짜 라벨,
  검색 묶음 제목 반복, 검색창 × 두 개, 모바일 첫 화면의 목차 버튼 겹침, 읽는 중 로고 사라짐, 바닥글 링크.
- 평가 C 뒤: 검색 색인이 `_`·`#`를 지워 `AUTONOMOUS_TRANSACTION`·`serial#`를 못 찾던 것, 발췌에 링크 주소가
  섞이던 것, 'Oracle' 결과가 관련도와 무관하게 글→위키 순이던 것, 글쓴이 표시와 글 끝 소개 링크, 날짜의
  `<time>` 요소, 1200px 미만 글 머리의 목차 버튼, 첫머리 안내 인용을 작은 글로, 판독이 어려운 작은 썸네일 제거,
  홈 제목(title), 바닥글 줄맞춤, 반투명 머리줄 비침.

### 운영 사이트(CUR, master에 배포)
- 검색: 긴 글 불이익 완화(사례 글이 1위), 한두 글자만 맞은 대체 결과는 '결과 없음', 방향키·Enter 조작,
  결과 종류 표시, 결과 없음에서 목록 링크, 강조색, 모바일 결과 압축, 위키 옆 목록을 색인에서 제외.
- 위키 빈 결과를 첫 화면 건수 줄에서 알리고 '조건 지우기'·'본문까지 전체 검색' 제공, 목록 날짜 형식 통일.
- 404 제목과 검색 버튼, 모바일 두 줄 머리줄을 읽는 동안 올려 둠, 초점 표시 2px 통일, 모바일 '검색' 글자.
- 다크 모드 홈 첫 화면 판 색, 먼저 읽을 글의 작성일, 넓은 화면 위키 문서의 글 중간 목차 버튼.
- 모바일 글 중간 목차, 목차 이동 뒤 초점, 사이트 글자만 모은 글꼴 1개(글꼴 전송 615KB → 205KB).

## 남은 것

### 디자인으로 고치지 않은 것(판단)
- CUR 글 끝 태그가 링크인 것만 테두리가 있는 모양: 누를 수 있는 것만 버튼 모양이라는 의도라 유지.
- CUR 푸터 '작성자 안내'가 편집 지침(/admin/)으로 연결: 작성자 작업 흐름이라 소유자 판단에 맡김.
- CUR 검색 발췌에서 `''`가 `"`처럼 보이는 것: 원문 HTML은 정상이고 Pagefind 발췌 표시 방식이라 보류.
- NEW 소개 페이지: 문장을 확정해 둔 상태라 시안에 옮기지 않았다. 실제 적용 때 조판만 바꾼다.

### 내용(작성자가 정할 것)
- 글 머리 요약이 '원인'뿐이라 결정·결과가 본문 뒤쪽에야 나온다(평가 C: 채용 담당자에게 가장 큰 영향).
- 주소 `address-search-9s-to-100ms`가 본문의 "9초에서 100밀리초로 튜닝했다는 뜻은 아니다"와 어긋난다.
- 첫 화면에 직무·주력 기술이 없다(소개 페이지에만 있다).
- 소개 페이지에 재직 기간·연차 같은 시간 맥락이 없다.
