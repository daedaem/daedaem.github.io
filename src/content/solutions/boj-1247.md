```javascript
const input = require("fs")
  .readFileSync(0)
  .toString()
  .split("\n")
  .map((el) => BigInt(el.trim()));

let idx = 0;
for (let i = 0; i < 3; i++) {
  const N = parseInt(input[idx]);
  const newarr = input.slice(++idx, idx + N);
  const result = newarr.reduce((init, val) => (init += val), BigInt(0));
  idx += N;
  if (!result) {
    console.log(0);
  } else if (result < 0) console.log("-");
  else console.log("+");
}
```

> **정리(2026-09-06):** 실행 폴더에 따라 달라지는 상대 경로 대신 표준입력 파일 디스크립터 `0`을 읽도록 바꿨다. 풀이 로직은 바꾸지 않았다.
