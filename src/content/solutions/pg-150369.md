```javascript
function solution(cap, n, deliveries, pickups) {
    let answer=0;
    let d = 0;
    let p = 0;
    for (let idx = n-1; idx>=0; idx--){
        let cnt =0;
        d+= deliveries[idx];
        p+= pickups[idx];

        while(d>0 || p>0){
            d-=cap;
            p-=cap;
            cnt++;
        }
        answer += (idx+1) *2 * cnt;
    }

    return answer;
}
```

> **바로잡음(2026-09-06):** 반복 조건의 `>= 0`을 `> 0`으로 고쳤다. 배달·수거 잔여량이 모두 0이면 추가 이동이 필요 없다. `solution(1, 1, [0], [0])`은 기존 코드에서 2를 반환했지만 0이어야 한다.
