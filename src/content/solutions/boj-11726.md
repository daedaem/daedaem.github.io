```javascript
const N = +require("fs").readFileSync(0).toString();

const dp = Array.from({ length: N + 1 }, (_, i) => (i === 1 ? 1 : i === 2 ? 2 : 0));

dp.forEach((_, i) => {
  if (i > 2) {
    dp[i] = (dp[i - 1] + dp[i - 2]) % 10007;
  }
});

console.log(dp[N]);
```

> **정리(2026-09-06):** 실행 폴더에 따라 달라지는 상대 경로 대신 표준입력 파일 디스크립터 `0`을 읽도록 바꿨다. 풀이 로직은 바꾸지 않았다.
