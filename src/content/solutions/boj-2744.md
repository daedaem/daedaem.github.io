```javascript
const input = require("fs")
  .readFileSync(0)
  .toString()
  .trim()
  .split("")
  .map((el) => {
    if (el >= "a" && el <= "z") {
      el = el.toUpperCase();
      return el;
    } else {
      el = el.toLowerCase();
      return el;
    }
  })
  .join("");


console.log(input);
```

> **정리(2026-09-06):** 실행 폴더에 따라 달라지는 상대 경로 대신 표준입력 파일 디스크립터 `0`을 읽도록 바꿨다. 풀이 로직은 바꾸지 않았다.
