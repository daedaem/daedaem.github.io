# 읽기 UI·표기 합의안 — 선행 변경본 승인 완료

후속 확인: 사용자 허용 후 Claude의 기존 검토 대화에 연결해 정확한 `ce6bb47`을 별도 재검증했다. Claude는 목차·복사 버튼·세 문서 표기 수정을 확인하고 배포에 동의했다. 아래의 대기 설명은 초기 상태의 기록이다. 추가 두 개선과 최종 배포 상태는 [후속 검토 기록](reading-refinement-2026-09-20.md)을 따른다.

기준: `88a9fd3` (`master`). 검토 브랜치: `codex/consensus-ux-20260920`.

사용자는 Codex와 Claude가 동의한 부분만 적용하고, 변경본 재검증 전에는 배포하지 않도록 요청했다. 기존 검토 대화의 반론 답변에서 아래 다섯 항목의 방향을 확인했다. 이 문서는 **구현 방향의 합의와 Codex 로컬 검증**을 기록한다. Claude의 정확한 변경본 재검증·배포 동의는 아직 받지 못했다.

## 구현한 범위

1. 사례·위키 목차: 서버 HTML의 열린 `details`와 no-JS 대안을 유지하면서 바로 뒤 동기 인라인 스크립트에서 초기 화면 분기를 적용한다. 본문 뒤 모듈은 최초 상태를 다시 덮지 않고 화면 분기 변경에만 반응한다. 사례 1200px, 위키 60rem 기준은 유지한다.
2. 코드 복사: 공통 버튼을 기존 44px 제어 크기로 맞추고 언어 라벨과 버튼을 별도 상단 공간에 둔다. 내부 `code`의 가로 스크롤, 테마, 키보드 초점, 터치 노출은 유지한다. 절충은 위키·노트·풀이의 코드 블록이 조금 높아진다는 점이다.
3. Spring 트랜잭션 위키: 제목·본문은 유지하고 요약에 `rollback-only`로 표시되지 않은 상태라는 조건을 명시한다.
4. Web Forms 위키: 비어 있던 비교 표의 첫 열 제목을 `비교 항목`으로 채운다.
5. NULL 사례: SQL 예제 주석을 `'NULL' (NULL 값이 아니라 문자열)`로 명시한다. 실제 경험이나 운영 SQL을 추가한 것이 아니다.

위키 두 편의 수정일만 저장소 규칙에 따라 2026-09-20으로 갱신한다. 최초 작성일, 사례 시점, 사례 수정일, 슬러그, 발행 상태, 홈·소개·브랜드·대표 글 순서·표지·호스팅·의존성은 변경하지 않았다.

## 채택하지 않은 항목

- 글 길이·코드 양만을 근거로 한 대표 글 교체.
- 서로 다른 기간 표기나 프로젝트 연도를 근거로 한 오류 단정.
- 화면 크기별로 번갈아 표시되는 위키 트리를 중복 접근성 결함으로 보는 주장.
- 과거 JDBC 변환 원인을 현재 기록보다 강하게 단정하거나 새 재현 결과를 만드는 서술.
- 추가 디자인·콘텐츠 제안: 이번 합의 범위에 포함하지 않았다.

이 항목들은 확인된 결함처럼 고치지 않는다. 작성자의 추가 확인이 필요한 실제 경험은 별도 문제다.

- `npm run check`: Astro 105개 파일, 오류·경고·힌트 0.

- `npm run check:site`: 619개 HTML, 내부 참조 21,750개 통과.
- `git diff --check`: 통과.
- 새 회귀 테스트 6개: 파싱 시점 목차 초기화, no-JS용 열린 마크업 보존, 늦은 모듈의 수동 토글 보존과 화면 분기 변경, 공통 44px 버튼·코드 스크롤 구조, 합의한 문구·제목 보호.

빌드 결과를 로컬 인앱 브라우저에서 확인했다.

- Web Forms 위키와 정수 범위 사례: 320/390/768/1440px에서 가로 넘침 없음. 좁은 화면 목차 닫힘, 1440px 목차 열림. 각각 복사 버튼 10개·7개 모두 44×44px 이상이며 코드와 겹치지 않음.
- Web Forms 위키: 목차 Enter 열기·닫기, 코드 키보드 가로 이동, 복사 버튼 Enter 후 성공 안내 확인. 비교 표 첫 열 제목 확인.
- TypeScript 학습 노트와 BOJ 5597 풀이: 320/1440px에서 가로 넘침 없음. 각각 버튼 27개·1개 크기 및 코드와 비중첩 확인.
- Spring 위키의 렌더링된 요약·작성/수정일과 NULL 사례의 예제 주석 확인.
- Web Forms 데스크톱 라이트, 정수 범위 사례 모바일 다크 화면을 직접 확인. 검증 후 라이트와 기본 화면 크기로 복원.

초기 CLS 수치, 실제 no-JS 브라우저, 실기기·실스크린리더는 이번 Codex 검증에 포함되지 않는다. 목차 수정은 늦은 모듈이 만드는 상태 변경을 앞당긴 것으로, 모든 환경에서 CLS가 0이라는 보장은 아니다. 전 콘텐츠 사실 확인이나 채용 효과 검증으로 해석해서는 안 된다.

## 재검증·배포 조건

Claude에 다섯 항목의 구현 범위를 전달했으나, 이후 검토 대화 접근이 차단되어 변경본에 대한 답변을 확인하지 못했다. 다른 비공개 대화에 접근할 위험이 있어 추가 접근을 멈췄다. 비공개 Notion·이력서 원문을 열거나 전달하지 않았다.

검토자는 이 브랜치와 `88a9fd3`의 차이를 확인하고, 특히 목차 초기 로딩·화면 분기·수동 토글·no-JS와 공통 코드 상단 공간을 재검증해야 한다. 문제 제기와 반론이 해소되고 정확한 변경본에 동의한 뒤에만 `master`에 반영한다. 현재 문서는 배포 완료나 최종 승인 기록이 아니다.
