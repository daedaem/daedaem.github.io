페이지 CSS 인라인은 첫 방문의 왕복 요청을 줄이는 대신 페이지를 옮길 때 HTML에 CSS를 다시 받는 선택이다. CSS 규칙·폰트·표지를 바꾼 것이 아니다. 같은 로컬 빌드 조건의 gzip HTML 크기는 다음과 같다.

| 페이지 | 외부 페이지 CSS | 인라인 페이지 CSS |
| --- | ---: | ---: |
| 홈 | 8,008 B | 14,282 B |
| 글 목록 | 8,891 B | 13,742 B |
| NULL 사례 | 13,199 B | 19,931 B |
| 위키 목록 | 13,795 B | 17,751 B |
