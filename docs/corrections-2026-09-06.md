## 검색·안내·접근성

- 알고리즘 하단의 공통 안내와 관련 문제, 아카이브 안내, 위키 목차를 검색 색인에서 제외했다. 제목과 본문은 검색에 남긴다.
- SCSA에는 개인 기록에 맞는 안내를 표시한다. 제목·본문·승인 이미지는 변경하지 않았다.
- 공통 풀이 안내에서 직접 저작을 일괄 단정하지 않는다.
- 코드 접기 버튼의 대상과 펼침 상태를 연결하고, 테마 버튼은 다음 동작을 이름으로 알리는 일반 버튼으로 정리했다.
- 검색 단축키 표시는 운영체제에 맞춰 Cmd/Ctrl을 구분한다.
- 소개 문구는 전 계층·속도에 대한 자기평가 대신 문제를 확인하는 행동으로 정리했다. 홈 제목·성과 3줄·이름·로고·색상은 유지한다.
